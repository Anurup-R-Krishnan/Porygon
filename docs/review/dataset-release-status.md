# Dataset release status

The CC BY 4.0 release contains 216 controlled-container pilot trial metadata records, an index, metadata, annotation guidelines, data dictionary, source provenance, full license terms and an offline integrity verifier.

Public release: https://github.com/Anurup-R-Krishnan/Porygon/tree/codex/technical-enrichment/datasets/porygon-pilot-v1.0.0

Run `python3 datasets/porygon-pilot-v1.0.0/verify.py` to check 228 file hashes, the 18-cell collection matrix and labels against original source records. Dataset version 1.0.0 identifies the established release; historical source bytes and pilot eligibility are preserved.

The release is trial-level metadata. See its readme and annotation guide for the collection design, label definitions and analysis scope. The individual submission package is retained locally under `artifacts/local/college-submission`; it includes personal certification documents and is separate from the public repository.
