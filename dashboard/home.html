System Architecture

Five-Stage Detection Pipeline

Every container event flows through a deterministic chain — from kernel probe to autonomous response.

01 / COLLECT
Collector
Discovers and fingerprints running containers via Docker API. Maintains a live registry of workload metadata.
Docker SDK · Python
02 / OBSERVE
Telemetry
Attaches eBPF probes via Falco to capture syscall-level events: process exec, network I/O, file operations.
Falco · eBPF · gRPC
03 / SCORE
ML Classifier
OCSVM + Isolation Forest ensemble trained on baseline behavioural profiles detects anomalies in real time.
scikit-learn · NumPy · GPU
04 / ENRICH
Scanner
Cross-references container images against the Trivy CVE database. Adds severity, CVSS, and exploit-path context.
Trivy · CVSS · NVD
05 / ACT
Responder
Executes autonomous containment: pause container, kill process, or isolate network. Full audit trail recorded.
Docker API · FastAPI · SQLite

Core Capabilities

What Porygon Does

capability-01 · process-telemetry

Syscall-Level Telemetry Ingestion

Falco eBPF probes intercept kernel syscalls in real time — exec events, network connections, file operations — without modifying container images or requiring privileged sidecars. Every event is timestamped, attributed, and spooled to the backend for analysis.

capability-02 · anomaly-detection

ML Anomaly Scoring

A dual-model ensemble — One-Class SVM for tight perimeter modelling and Isolation Forest for outlier isolation — scores each container's behavioural fingerprint against a trained baseline. Drift triggers configurable alert thresholds.

capability-03 · vulnerability-enrichment

CVE Vulnerability Enrichment

Container images are periodically scanned by Trivy against the NVD CVE database. Results are cross-referenced with runtime telemetry to surface exploitable vulnerabilities with open ports or observed execution paths.

capability-04 · containment-response

Autonomous Containment

When anomaly scores exceed thresholds, the responder acts immediately: pausing the container, killing specific processes, or severing network egress — with a complete audit trail written to the incident log for forensic replay.
